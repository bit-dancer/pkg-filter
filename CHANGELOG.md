# Changelog

Все существенные изменения в проекте Debian Package Filter Proxy.

## [2.0.0] - 2024-05-20

### Производительность и оптимизация памяти

#### Добавлено
- **SQLite таблица `packages_depends`** для эффективного хранения и поиска зависимостей
  - Индексы для быстрого поиска: по repo_id, package_name, depends_on
  - Составные индексы для ускорения разрешения зависимостей
  - Поддержка типов зависимостей: depends, pre-depends, recommends, suggests

- **CacheManager** для кэширования Package файлов на диске
  - Файлы сохраняются в `data/cache/{repo_id}_{datetime}.{ext}`
  - Атомарная запись: файлы записываются с префиксом `_`, после завершения синхронизации префикс убирается
  - Защита от отдачи клиенту неполных/битых файлов во время синхронизации
  - Автоматическая очистка старых версий (настраиваемое количество файлов и срок хранения)

- **Статусы пакетов** в таблице packages
  - `active` — пакеты включены в фильтрацию
  - `ignored` — пакеты исключены правилами фильтрации
  - `required` — пакеты добавлены как зависимости
  - `stale` — устаревшие версии пакетов
  - Поле `filter_reason` хранит причину исключения (excluded_by_rule, old_version_removed, dependency_unresolved)

- **Изоляция репозиториев**
  - Уникальный ключ `(repo_id, package_name, version)` предотвращает пересечение пакетов
  - Каждый репозиторий работает независимо

#### Изменено
- **Оптимизирован алгоритм разрешения зависимостей**
  - Использование SQL запросов с индексами вместо BFS в памяти
  - Потоковая обработка пакетов из upstream
  - Асинхронная синхронизация с кэшированием результатов

- **Улучшена работа с версиями пакетов**
  - Быстрый поиск последней версии через индексированный запрос
  - Оптимизированная сортировка версий Debian

- **Метод `savePackages`** теперь сохраняет зависимости в отдельную таблицу
  - Парсинг зависимостей Debian формата
  - Массовая вставка для производительности

#### API
- Новые методы RepoManager:
  - `getPackageDependencies(repoId, packageName, version?)` — получение зависимостей из БД
  - `findReverseDependencies(repoId, dependencyName)` — поиск reverse dependencies
  - `getLatestVersion(repoId, packageName)` — быстрый поиск последней версии
  - `resolveDependenciesWithDB(...)` — разрешение зависимостей через SQLite
  - `getPackagesByStatus(repoId, status)` — фильтрация пакетов по статусу
  - `getFilterStats(repoId)` — статистика по причинам фильтрации

### Технологии
- **Bun** — runtime для выполнения TypeScript
- **SQLite** — встроенная база данных для хранения метаданных пакетов
- **Потоковая обработка** — минимизация использования памяти при работе с большими репозиториями

### Совместимость
- Требуется Bun последней версии
- Системная утилита `gpg` (опционально, для подписи репозиториев)

## [1.0.0] - 2024-05-15

### Первый релиз

#### Возможности
- Фильтрация пакетов по имени, версии и приоритету (RegExp правила)
- Управление версиями: оставление N последних версий или версий по шаблону
- Автоматическое разрешение зависимостей с поддержкой кросс-репозиторного поиска
- Прозрачный прокси: отдает отфильтрованные Packages.gz и делает 301 Redirect на .deb файлы
- Поддержка GPG подписи репозиториев
- Конфигурация через JSON файлы

#### API
- `GET /r/:repo/sync` — принудительная синхронизация
- `GET /r/:repo/packages/list` — список отфильтрованных пакетов
- `GET /r/:repo/dists/:dist/...` — прокси метаданных репозитория
- `GET /r/:repo/pool/...` — редирект на оригинальные .deb пакеты
